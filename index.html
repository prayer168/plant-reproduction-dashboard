種子繁殖

Seed Reproduction
有性繁殖

透過花粉與卵細胞結合，形成種子，再由種子萌發成新植株。是植物最常見的繁殖方式。

代表植物
玫瑰 向日葵 番茄 豆類 稻米
✓ 基因多樣性高 點擊查看詳情 →
🍄

孢子繁殖

Spore Reproduction
有性繁殖

不需開花，由孢子體產生大量孢子，孢子散落後萌發，是蕨類、苔蘚的主要繁殖方式。

代表植物
腎蕨 木賊 地錢 水龍骨
✓ 數量龐大、散播遠 點擊查看詳情 →
🥔

地下莖繁殖

Rhizome / Tuber
營養繁殖

植物以地下莖（根莖、塊莖、球莖、鱗莖）儲存養分，並長出新芽，形成新個體。

代表植物
馬鈴薯（塊莖） 薑（根莖） 洋蔥（鱗莖） 慈姑（球莖）
✓ 快速、養分充足 點擊查看詳情 →
🍓

走莖繁殖

Stolon / Runner
營養繁殖

母株延伸出水平走莖，在節點處長出新的不定根與芽體，形成子株，再與母株切離。

代表植物
草莓 吊蘭 薄荷 虎耳草
✓ 自然蔓延、易操作 點擊查看詳情 →
🍃

葉芽繁殖

Leaf Propagation
營養繁殖

落地生根等植物的葉緣或葉片上直接長出小芽與小根，落地後即可發育成新植株。

代表植物
落地生根 玉米石 非洲菫 石蓮花
✓ 不需根莖、易繁殖 點擊查看詳情 →
✂️

分株繁殖

Division
無性繁殖

將母株分割為帶根帶芽的數個小株，各自獨立種植，每株皆能長成完整植物。

代表植物
文心蘭 虎尾蘭 白鶴芋 萬年青
✓ 保留親代特性 點擊查看詳情 →
✂️🌿

扦插繁殖

Cutting
人工繁殖

截取莖、葉或根的一段，插入土壤或水中，讓其重新長出根系，成為獨立植株。

代表植物
玫瑰 九重葛 地瓜葉 木薯
✓ 成本低、操作簡單 點擊查看詳情 →
🔗

嫁接繁殖

Grafting
人工繁殖

將優良品種的芽或枝（接穗）接合到健壯砧木上，使二者癒合生長，兼具兩者優點。

代表植物
蘋果 梨 柑橘 西瓜（砧木）
✓ 結合優良性狀 點擊查看詳情 →
🔬

組織培養

Tissue Culture
人工繁殖

在無菌環境中取植物的細胞或組織，放入含養分的培養基，大量快速繁殖出相同植株。

代表植物
蘭花 香蕉 草莓 馬鈴薯脫毒苗
✓ 大量複製、無病毒 點擊查看詳情 →

🌳 繁殖方式分類樹狀圖

  • 🌱 植物繁殖方式
    • 🌸 有性繁殖（需受精）
      • 🌰 種子繁殖 — 花粉＋卵細胞 → 種子萌發
      • 🍄 孢子繁殖 — 孢子散落萌發（蕨類、苔蘚）
    • 🍀 無性繁殖（不需受精）
      • 🌿 營養繁殖（利用植體）
        • 🥔 地下莖 — 根莖／塊莖／球莖／鱗莖
        • 🍓 走莖 — 匍匐莖末端長子株
        • 🍃 葉芽 — 葉緣長出不定芽
        • ✂️ 分株 — 分割帶根子株
      • 🧑‍🌾 人工繁殖（人為操作）
        • ✂️🌿 扦插 — 取莖葉插入介質生根
        • 🔗 嫁接 — 接穗＋砧木癒合共生
        • 🔬 組織培養 — 無菌環境細胞大量增殖
